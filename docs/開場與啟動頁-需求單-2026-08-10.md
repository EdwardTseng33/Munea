**⚠ 前置條件**：「兩週沒上線就登出」這條規則目前**還沒有**，登入是一直留著的。要做是另一件事。

## 3. 啟動頁

**畫面**：米黃底，中央是標誌（只有水滴與漣漪，不含米色圓角方塊），下方品牌字與副標。

**品牌字一律照官網 `app-site/warm.css` 的寫法，不得自創**：

```html
<span class="logo-word">Mu<b>nea</b><span class="logo-zh">沐寧</span></span>
```

| 部位 | 規格 |
|---|---|
| 整組 | Poppins 700、字距 -0.025em、色 `#33403D` |
| `Mu` | 墨綠 `#33403D` |
| `nea` | **薄荷綠 `#3AA8A0`** ← 品牌字的特徵，最容易漏 |
| `沐寧` | Noto Sans TC 700、0.78 倍字級、字距 0.04em、左邊距 9px、透明度 .95 |

**副標**：全家人的健康陪伴AI照護管家（Noto Sans TC 400、`#6B7B76`）

**動畫**（照「像真的水滴滴到水面」設計）

| 時間 | 發生什麼 |
|---|---|
| 0s | 品牌字與副標**一開始就在**，不延遲浮現 |
| 0.25s | 水滴落下，**越接近水面越快**（重力加速） |
| 0.93s | 碰到水面，水滴被壓扁再回彈（表面張力） |
| 0.93s | **同一刻**內圈波從接觸點爆開 |
| 1.06s | 外圈波追出去，兩圈都先快後慢停在定位 |

- 兩圈波是官方標誌拆出來的素材（`munea-wave-inner.png` / `munea-wave-outer.png`），**不另外畫線條**
- 手機開了「減少動態效果」→ 整組不動，直接顯示定格

**播多久**：平常約 1.6 秒；第一次（要接開場三頁）約 2.4 秒。資料還沒載好就定格等著——動畫剛好蓋住等待，不會出現空白畫面。

**⚠ 還沒處理的一層**：iPhone App 自己有一張系統啟動圖（送審附的靜態圖），會在動畫**之前**先閃一下。那張圖要用同樣的米黃底、標誌放同樣位置，接起來才無縫；不然每次開機都會跳一下。

## 4. 開場三頁

順序＝**陪伴聊天 → 用講的就能記 → 全家人的陪伴**（對應官網功能 02 → 01 → 03）。
先給溫度，再給實用，最後放大。

| 頁 | 主標 | 副標 |
|---|---|---|
| 1 | 家人的健康，<br>終於有人一直記得 | 沐寧有臉、有聲音，像視訊一樣陪爸媽聊天，這次從上次聊到的地方接著聊。 |
| 2 | 想記什麼，<br>跟她說一聲就好 | 吃藥、回診、要問醫生的事——用講的就記下來，時間到了手機會提醒你。 |
| 3 | 不只陪爸媽，<br>是陪一家人 | 把家人加進家庭圈，健康和心情互相看得見；一起比步數、玩機智問答，在外地的人也放得下心。 |

**版面**：不放標誌、不放品牌字、**不放「略過」**（有「下一步」就不需要出口）。
插圖滿版置中、主標與副標置中、底部圓點、最下方單一大鈕（前兩頁「下一步」，第三頁「開始使用」，白底深綠字）。

**插圖**：三張同一位長輩、同一個沐寧貫穿（她在第 1、2 頁的手機裡、第 3 頁客廳桌上的手機裡）——正好是主標那句話的畫面版。
三張先裁掉透明邊再統一縮放到**相同寬度**，翻頁才不會忽大忽小。

---

## 5. 守住的線

- **不自創標誌**：只用官方檔案，動畫只做拆解與位移
- **不要陰影與漸層**（Edward 拍板扁平化，官網用 `!important` 全站強制）
- **深綠 `#236C66` 只當文字**，不得當主色或按鈕底（7/30 重申，違者退回）
- **橘只做底色與圖形**，不做文字色
- 文案不出現「追蹤／監測」、不做醫療宣稱、不寫沒有的功能
- **提醒是手機通知，不是她開口念**——文案不得寫「親口喊你」

## 6. 施工紀錄（2026-08-10）

**動到的檔案**

| 檔案 | 做了什麼 |

| `web/index.html` | 啟動頁與開場三頁的畫面、6 秒保險絲 |

| `docs/I18N-NON-USER-FACING-REVIEW.json` | 品牌字「沐寧」登記為 `brand-proper-noun` |
| `scripts/test-brand-lockup-not-translated.js` | **新增**：守品牌字規格（含 nea 是薄荷綠） |
| `scripts/test-app-surface-manifest.js` | 畫面總數閘門 38→39 |
| `scripts/app-i18n-fixture-server.js` | 驗收工具供檔時收掉兩個覆蓋層 |
| `scripts/app-full-surface-i18n-browser-precheck.js` | 認得開場三頁、橫向滑動不算溢出 |
| `web/onboarding-assets/` | **新增** 六張 WebP 素材 |

**兩個關鍵決定**

1. **不重用 `ONBOARDING_COMPLETED_KEY`**：那是舊迎賓精靈的記號，現在還被拿來決定要不要跑帳號初始化。
   改掉它的意思會動到通話路徑，所以開場三頁用新的 `munea.onboardingIntroSeen.v1`。
2. **啟動頁預設顯示 + 6 秒保險絲**：不預設顯示會先閃一下首頁；但預設顯示又可能在程式出錯時把 App 鎖死，
   所以配一段跟 app.js 無關的 inline script 兜底。

**順手修掉的兩個既有缺陷**（跑全畫面驗收時抓到，與本次改動無關，已用暫存改動驗證過）

- 首頁任務標題：英文與西班牙文被寫死「不換行、超出切掉」，最大字級下 `Salir a caminar` 只放得下 77px（需 107px），
  使用者看到半截字 → 改成可換行。
- 用藥提醒的「稍後」按鈕：並排按鈕沒設 `min-width: 0`，西班牙文＋最大字級時整顆推出畫面 11px → 已修。
