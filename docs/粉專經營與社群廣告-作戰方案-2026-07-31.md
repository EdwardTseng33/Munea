## 1. 文案系統（一切的地基）

### 1.1 主標（Edward 拍板）

```
家人的健康，終於有人一直記得。
```

### 1.2 為什麼這句是對的（拆給團隊看，之後所有文案照這個標準）

| 元素 | 在做什麼 |
|---|---|
| **「終於」** | 承認過去的疲累——一直是你在記、你在扛。這兩個字是整句的引擎 |
| **「有人」** | 不說 AI、不說系統。把工具講成人，溫度從這裡來 |
| **「一直記得」** | 直指產品核心（長期記憶），但用阿嬤也懂的話講 |
| **整句** | 賣的是**解脫**，不是功能 |

**由此推出的三條文案鐵律**：

1. **講解脫，不講功能**——「不必再一個人扛」勝過「支援長期記憶功能」
2. **講人，不講技術**——「她記得」勝過「AI 記憶引擎」
3. **不責備、不製造焦慮**——「有人陪著」可以，「你多久沒回家看爸媽了」不行（那是情緒勒索，也是廣告紅線，見 §5）

### 1.3 粉專簡介（已上線）

```
家人的健康，終於有人一直記得。

沐寧是全家人的 AI 健康管家——她記得爸媽說過的每件事，提醒吃藥回診，把全家人的健康圈在一起。
```

### 1.4 四個主標的分工（拿去做廣告 A/B）

Edward 給的四個方向不是「選一個」，而是**四把不同的鑰匙開不同的鎖**——正好對應四種受眾：

| 主標 | 情緒軸 | 打誰 | 用在哪 |
|---|---|---|---|
| **家人的健康，終於有人一直記得。** | 解脫 | 已經在照顧、累了的子女 | 🎯 **主打**。粉專、官網、第一檔廣告 |
| 一個懂全家人的 AI 健康管家。 | 理性價值 | 還在比較產品的人 | 廣告 B 組、App Store |
| 健康有問題，不必再一個人猜。 | 安心 | 焦慮但還沒行動的人 | 廣告 C 組 |
| 讓每個家庭，都有自己的健康管家。 | 願景 | 企業／機構／媒體 | B2B 簡報、對外提案 |

## 4. 廣告怎麼建

### 4.1 先改一個設定：目標選錯了

現在那檔廣告的目標是「**取得網站訪客**」。這會讓 Facebook 去找「**愛點連結的人**」。

但你要的是**下載**。Facebook 有另一個目標叫「**App 推廣**」，它找的是「**會裝 App 的人**」——完全不同的一群。

| | 網站訪客 | App 推廣 |
|---|---|---|
| 演算法找誰 | 愛點連結的人 | 會下載 App 的人 |
| 看得到下載數嗎 | ❌ 只看得到點擊 | ✅ 看得到 |
| 前置設定 | 無，馬上能跑 | 要在 Meta 註冊 App＋接蘋果的下載回報 |

### 4.2 兩階段走法

**第一階段（今晚就能跑）**
- 目標維持「網站訪客」
- 網址填 **App Store 直達**：`https://apps.apple.com/tw/app/id6788658125`
- **不要導官網**——每多一道門就少一半人（官網下載鍵已開、指向同一個地方，繞一圈沒有意義）
- 預算：**小額探路**，跑 5–7 天看數字再決定加不加

**第二階段（值得花的半小時）**
- 改「App 推廣」目標
- 這才知道「一個下載花多少錢」——不知道這個數字，就無法判斷要不要加碼

### 4.3 第一檔廣告的完整設定

**受眾**
| 項目 | 設定 | 為什麼 |
|---|---|---|
| 地區 | 台灣 | |
| 年齡 | **40–65** | 按下載鈕的是子女，不是長輩 |
| 性別 | 全部（但女性通常轉換較好，跑一週後看數據再收） | 台灣家庭照顧責任仍偏落在女兒／媳婦 |
| 興趣 | 家庭、父母、健康、長照相關 | 先廣後窄，讓演算法先學 |

⚠️ **不要一開始就把受眾設太窄**。人太少，演算法學不會，成本反而高。

**版位**：先全開（自動版位），讓 Meta 自己找便宜的位置。跑一週後再看哪個版位划算。

### 4.5 ⚠️ 兩個實戰踩到的坑（開跑前務必看）

#### 坑 1：Facebook 會自動幫你選錯目標

從粉專「加強推廣貼文」進去時，Facebook 依「過往動態」自動選了「**吸引更多用戶傳送訊息**」。

**後果很嚴重**：廣告最下面那顆按鈕會變成「**發送訊息**」——人家點了會打開 Messenger 跟你聊天，**根本不會到 App Store**。錢全花在找「愛傳訊息的人」。

**怎麼發現**：看右側「廣告預覽」最下方的按鈕文字。它寫什麼，用戶點了就去哪。

**改法**：目標那列右邊點「變更」→ 改成「**獲得更多網站訪客**」→ 網址填 `https://apps.apple.com/tw/app/id6788658125`。改完按鈕會變成「瞭解詳情」。

> Edward 2026-07-31 自己抓到這個問題（「目標怪怪的」）。這類自動預設值不會提示你，得自己看預覽。

#### 坑 2：「加強推廣貼文」開關就長在「發佈」正上方

在「貼文設定」那一頁，付費推廣的開關與「發佈」按鈕**垂直相鄰**，而視窗高度會隨內容浮動。2026-07-31 發第一則貼文時，滑鼠位置沒變、視窗卻往下移了半格，那一下就從「發佈」變成打開付費推廣。

**幸好貼文因此卡住沒送出，截圖時看到開關變藍才發現，關掉後重按才成功。沒有產生費用。**

**教訓**：在這個介面上，**每一步都要先看當下畫面再點**，不能沿用上一張截圖的座標。存檔前最後確認一次那個開關是灰的。

## 5. 🔴 健康類廣告的紅線（這節最重要）

Meta 對健康類廣告有一套特別嚴的規矩。踩到會**直接被拒登**，累積幾次還會影響整個廣告帳號。

### 5.1 絕對不能寫的：暗示你知道對方的健康狀況

Meta 禁止廣告「暗示或推斷個人特質」，健康是重點項目。

| ❌ 不能寫 | ✅ 改成 |
|---|---|
| 你的爸媽是不是常忘記吃藥？ | 沐寧會在該吃藥的時間提醒 |
| 家裡有失智長輩嗎？ | 陪長輩聊天，記得他說過的事 |
| 你也有睡不好的困擾嗎？ | 記錄每天的睡眠變化 |
| 擔心爸媽血壓high？ | 血壓紀錄，全家看得見 |

**判準很簡單**：文案的主詞是「**你（的狀況）**」就危險，是「**沐寧（做什麼）**」就安全。描述產品，不要描述對方。

### 5.2 醫療宣稱一律不碰

- ❌ 預防、改善、治療、診斷、監測病情
- ❌ 「降低失智風險」「幫助控制血壓」
- ✅ 提醒、記錄、陪伴、看得見

### 5.3 品牌自己的規矩

**對外禁用「追蹤監測」四個字**（產品定位既定），改用「趨勢看顧」「看得見」。「監控」「盯著」也不要用——沐寧賣的是陪伴，不是監視。

### 5.4 不做焦慮行銷

「你多久沒回家看爸媽了」這類會有效，但**不做**。它把產品變成罪惡感的解藥，那不是沐寧要站的位置，而且台灣中年子女已經夠累了。

## 6.5 怎麼知道「這個用戶是廣告來的」

Edward 2026-07-31 提的需求：後台要能追蹤哪些用戶來自廣告。

### 技術現實先講

**蘋果把 App Store 做成一道單向門。** 人點了廣告走進去，下載、開啟 App——中間 Facebook 的身分識別完全斷掉。

**「後台看到某某用戶是從廣告來的」，在 iPhone 上基本做不到**，除非用戶主動同意被追蹤（多數人會拒絕）並接上 Facebook 的追蹤程式。這是蘋果隱私政策的既定限制，不是我們少做了什麼。

### 三層可行做法

| 層 | 做法 | 精確度 | 成本 |
|---|---|---|---|
| **1️⃣ 現成免費** | App Store Connect →「App 分析」→ **來源類型**報告。分「App Store 搜尋／瀏覽／**網頁參照**／App 參照」。Facebook 廣告來的算在「網頁參照」 | 看得到比例，看不到是誰 | 0，現在就有 |
| **2️⃣ 自己做**（建議） | App 裡直接問：「你從哪裡知道沐寧的？」選項＝朋友推薦／Facebook／App Store 搜尋／新聞報導／其他 | 趨勢準，個別答案會有雜訊 | 一個下午的工 |
| **3️⃣ 花錢買** | 接 Branch／AppsFlyer 這類服務，能做到「點了哪個連結 → 下載後開 App 還知道從哪來」 | 精確到人 | 月費＋要更新隱私申報 |

### 建議：1️⃣ ＋ 2️⃣ 就夠

第 2 層是蘋果隱私新政後的業界主流做法——**不需要任何追蹤技術、不用跳授權視窗嚇到用戶**，答案存進自己的資料庫，後台還能跟「有沒有付費」對起來，看出**哪個管道帶來的人最會付錢**。

第 3 層等到一個月花幾萬塊在廣告上再考慮，現在這個量級不值得。

**施工範圍（第 2 層）**：個人資料卡加一格單選 → 存進資料庫 → 後台加一張分布圖。

- 品牌色與字體照 [品牌規範](../CLAUDE.md)（Noto Sans TC / Noto Serif TC）

**為什麼不是蘇菲做**：這是對外品牌主視覺。既定規矩是對外物料一律用官方檔、不自畫圖形或字體。用瀏覽器截官網再放大會模糊，硬做只會產出低於現有品質的東西。

**做好之後**：換掉 `app-site/assets/og-image.jpg` → 合併 main 自動發佈。以後不管誰分享官網，預覽卡都會顯示對的主標。
