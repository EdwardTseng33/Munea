# 四語系上架——Edward 動手清單（2026-08-02）

> 工程側 2026-07-31 完工。這份清單是「只有你能做」的部分。照順序做，每一步都有「怎麼算完成」。
>
> **7/31 當天多做的三件事，驗收時要順便看**：
> 1. **個人資料的「所在地」不再是兩格下拉**，改成一行「她記得你住在○○」——聊天講過一次她就記起來，打錯或搬家可以自己改。所以驗收時**不要找縣市選單**，看那一行在不在、改不改得動。
> 2. **她開始會問住處**：問到天氣、附近吃什麼、有什麼好去處時，她會自然問一次「你住哪一區」，聽清楚就複誦確認、沒把握就給選項問（「南港還是南崗？」）。這是刻意的，不是 bug。
> 3. **各國有各自的說明書**（日文用日本的急難號碼與漢方、英文用美國的、西班牙文用當地的）。但**語系開關還鎖著**，所以這次驗收看到的仍是中文行為——除非你決定先開。

## 第 0 步 · 合帳與打包（約 30 分）

1. 確認 GitHub 上 i18n 批次 PR 全數合併、主分支綠燈（Actions 四關全過）。
2. 開 Xcode → 把 Build number 往上加一號（**不能用 Build 500 舊包**——那顆不含四語系）。
3. Archive → 上傳 App Store Connect，等 processing 跑完。
   - ✅ 完成標準：App Store Connect 看得到新 Build、狀態「可選取」。

## 第 1 步 · 實機四語驗收（每語系約 40 分，共約 2.5-3 小時）

手機「設定 → Munea → 語言」逐一切 中文／English／日本語／Español，每個語言做：

1. **38 畫面走查**：首頁、狀態（今天/7天/30天）、家人、活動（發起/走路/問答/揪一攤/投票/抽獎）、用藥、回診、報告、設定、個資、訂閱、加值、意見、安全通知、選角、興趣、邀請/加入圈、版本頁……（完整清單照 `web/src/i18n/app-surface-copy-manifest.json` 的 38 州）。
   - 看什麼：有沒有殘留中文（英日西模式下）、句子有沒有斷版、名字/數字有沒有帶對。
2. **10 張風險圖**：訂閱方案卡、付費牆、點數卡、同意頁（急難號碼行）、用藥提醒視窗、安全通知、報告期間列、活動出缺席卡、選角說明、NPS 打分——各拍一張存檔。
3. **通話全鏈**（硬 Gate）：按通話 → 麥克風授權 → 領席 → 臉＋聲音回來 → 講一句有回應 → 掛斷釋位。
4. **混語測試**：介面英文時用中文講話、介面日文時用英文講話——確認能正常對話、介面字不跳掉。
   - ✅ 完成標準：四語都走完、風險圖 40 張存到 `docs/qa/i18n/<語系>/`。

5. **順手看兩個 7/31 改動**：①個人資料的所在地是一行字、可以自己改（不是下拉選單）②通話中問她「今天天氣如何」，看她會不會問你住哪一區、答了之後有沒有複誦確認。

## 第 2 步 · 8 個內購 Sandbox（約 40 分）

1. 手機掛 Sandbox 測試帳號（設定 → App Store → 沙盒帳號）。
2. 在英文介面下，把 8 個商品各買一次：Plus 月/年、Pro 月/年、加值點數 4 檔。
3. 看三件事：價格顯示當地格式、購買完成訊息是英文、點數/方案真的到帳。
   - ✅ 完成標準：8 筆都完成、無卡單。

## 第 3 步 · App Store Connect 唯讀對帳（約 20 分 · 需要你的 API 鑰匙）

1. 把 App Store Connect API 鑰匙（.p8）交給蘇菲掛進工具（唯讀權限即可）。
2. 蘇菲跑對帳腳本：四語 metadata、8 內購在地化、上架地區與價格快照落檔 `docs/qa/i18n/app-store-connect-audit.json`。
   - ✅ 完成標準：`node scripts/i18n-release-readiness.js` 的 appStoreMetadata／marketAvailability 兩關轉綠。

## 第 4 步 · 要不要開語系（你拍板）

各國的人設說明書（她講話的規矩、當地急難號碼、當地醫療體系）四國都寫好了，但**都還沒有母語者看過**。語系開關現在是關的，開了才會有外國用戶真的用到。三個走法：

- **A（建議）**：找當地有照護背景的人各看一次，日文優先（日本高齡市場最大、錯了最傷）。最穩，但要找人。
- **B**：先只開英文——你自己判斷得了，而且美國用戶對 AI 的容錯高一些。
- **C**：三語都開、標成搶先體驗。最快，但急難號碼或醫療說法出錯的風險由我們自己承擔。

⚠ 無論哪個走法，開之前都要跑一次各國安全題組（每國三題，考她會不會在長輩推辭時軟化、會不會贊成停藥、想不開時給的號碼對不對）。這個要花錢，跑之前我會先跟你說要花多少。

## 第 5 步 · 送審（約 15 分）

1. App Store Connect → 新版本描述欄**確認 EULA 連結還在**（7/26 退件教訓：賣訂閱的描述欄 EULA 連結永遠不能刪）。
2. 四語 metadata、截圖掛好 → 「新增以供審查」→ 送出。
3. 語系開關（`web/src/i18n/catalog-manifest.json` 的 en/ja/es runtimeEnabled）＝**全部關卡綠了才開**、開了才包最終送審版。
