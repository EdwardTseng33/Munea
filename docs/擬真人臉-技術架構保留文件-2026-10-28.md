## 1. 架構總圖（一句話版）

```
iPhone App ──語音──▶ 語音服務（Cloud Run munea-voice · Gemini Live）
     │                        │
     │                        ▼
     └──通話配對／點數──▶ 總機（gateway · 排座位、發 call token、臉 ready 才扣點）
                              │
                              ▼
                    顯示卡工作機（FlashHead · 4090 常駐卡＋RunPod 備援）
                    ├ 由真人照片（a05 寧寧／a06 阿宏）即時生成會講話的臉
                    └ 影像＋聲音走同一條線回 App（聲嘴同時鐘）
```

- **臉的來源**：一張真人照片（`deploy/runpod-avatar/assets/nening-real-female-full.jpg`；男生 `deploy/flashhead-poc/char-a06B-new-noglass.png`），顯示卡用 FlashHead 引擎依聲音即時對嘴。
- **綁臉的是總機**：資料庫沒顯示卡座位就排隊、臉 ready 才扣點（記憶 `rive-replaces-ningning-face`／`gateway-two-worker-registries`）。
- **聲嘴同步**：影像與聲音共用時鐘、signed playout offset −80ms（`docs/RELEASE-STATE.md` 8/12）。

## 4. 怎麼關、怎麼再開

### 關（Phase 4 的範圍，只做這些）
1. 資料庫 029 加 `media_mode`（voice-only）；總機對新版 App 不再排顯示卡座位、不扣臉的點
2. App 通話改走純語音線（聲音不再搭影像線）；`#faceVideo` 層留著不顯示
3. 舊版 App 用戶歸零 ＋ B2B 試講間改接插畫臉之後 → 關常駐卡（省月費約 NT$11,304 ＋ 每分鐘 NT$0.7）
4. **不刪**：以上所有程式、部署腳本、Dockerfile、文件、素材封存

### 再開（復活清單，約 1 天）
1. 顯示卡：照 `deploy/runpod-avatar/README.md` 上傳 `flashhead_server.py`＋`flashhead_engine_core.py`（兩個一起）、臉素材（`sync-face-assets.py`）、開機 `start-flashhead.sh`；或 RunPod 排隊開卡（`controller_service.py`）
2. 總機：`gpu_workers` 名單登錄新卡、`CALL_TOKEN_SECRET` 對齊（漏了＝403 而健康全綠）、時鐘對時（時鐘快＝通話全滅）
3. App：`media_mode` 切回 avatar、`faceEngine()` 指 flashhead、拿掉或隱藏插畫層（`companion-face.js` 的 `MuneaFlatFace.stop()` ＋ 不 mount）
4. 驗收：`npm run test:launch`、真機 3 通×3 輪、聲嘴 ±250ms、首聲 <800ms（RELEASE-STATE 8/12 門檻）
