## 2. 施工順序（四個階段、各自一個 PR）

### Phase 0 ✅ 動態定案（已完成，在 `feat/ningning-rig-20261026`）
正視前方版引擎＋ 144KB 素材；demo：`ningning-front-only-20261028.mp4`。

### Phase 1 · App 換裝（併 #607 一起上）
1. 從原稿裁 `ningning-face.webp`（臉部特寫）＋ `ningning-full.webp`
2. 換掉 1-1 表的 8 處引用（`index.html` 7 處、`app.js` 1 處、`companion-profile.js` 3 欄位）
3. 刪舊素材 ~20MB（寧寧＋阿宏）
4. 驗收：四語 × 8 個畫面截圖（首頁、狀態、設定、角色選單、聊聊待機、聊聊通話中、同意卡、吃藥提醒）；卡西法跑流程測試（`test:ui-contracts`、i18n 兩支、`smoke:no-api`）、女巫看截圖
5. 併入 main → Mac 打包（版號＋更新說明）→ 送審

### Phase 2 · 官網＋B2B 頁（合併 main 自動發佈）
1. 用 `demo-video.js` 產三支短片：官網打招呼（約 6 秒）、B2B idle（約 8 秒循環）、B2B 四語試講（用現成四語聲音）；各抓一張海報 jpg
2. 新 `og-image.jpg`（官網）；B2B 五張 App 截圖用 Phase 1 的新版 App 重截
3. 文案四語改：示範卡名字→寧寧、「真人／擬真」→「會動的插畫夥伴」、拿掉男生
4. `npm run site:build`、`npm run b2b:build` → 看四語頁面截圖 → 併入 main

### Phase 3 · 商店截圖
新 build 上 TestFlight 後，照 `screenshot-plan.json` 四語各 5 張重拍、上傳 App Store Connect（送審時一起換）。

### Phase 4 · 雲端顯示卡退場（省月費）
1. 後端：資料庫 029 加 `media_mode`（voice-only）、總機不再為新版 App 開卡、假手機純語音閘門
2. App：通話改走純語音線（聲音不再搭顯示卡的影像線）
3. B2B `call.html` 改走同一套
4. 舊版 App 用戶歸零 ＋ B2B 試講收卡後 → 關常駐卡、`demo-cloud` 下架
