# 人設說明書 · 一國一本（2026-07-31 起）

> Edward 2026-07-31 拍板：「不同國家的人下載，知道他的語系就要用那個國家的人設說明」「語音聊天的口語風格同上也要調整」。

## 為什麼改

在此之前，所有語系拿到的都是同一本繁體中文台灣版說明書（約 10KB：台灣急難號碼 119／1925／1995、健保中醫、「全程只能用自然的台灣國語」），非中文的通話則在**最後附一段英文紙條**，要模型「忽略上面所有台灣專屬的例子、文化預設與專線號碼」。

三個問題：

1. **模型要自己壓抑 10KB 的指令**——壓不乾淨的部分會漏出來（拿台灣專線號碼給日本長輩是安全事故等級）。
2. **每輪重新計費**——常駐說明書已經是 6,481 tokens（2026-07-29 量測），非中文用戶付的是「用不到的內容」的錢。
3. **文化不是翻譯**——日本長輩拒絕就醫最常見的理由是「不想給人添麻煩」，台灣版說明書裡沒有這一條，翻譯過去也不會有。

## 怎麼放

```
engine/persona/
  core.<語系>.txt            人設主書（⓪～⑦-B 全部章節）
  red.<語系>.txt             安全紅線（①～⑥）
  lookup-offline.<語系>.txt  沒有查詢能力時的即時資訊規則
  lookup-online.<語系>.txt   有查詢能力時的即時資訊規則
  voice-style.<語系>.txt     語音口語風格（話量／溫度／開場／句尾／說故事／接住情緒）
```

取用：`chat_engine.core_instruction(lookup, locale)`、`chat_engine.red_lines(locale)`、`chat_engine._persona_text("voice-style", locale)`。

**語系從哪裡來**：語音線用 `locale_profile["sessionLocale"]`（這通實際講哪種語言），不是介面語言——介面英文但講日文的長輩要拿到日文書。文字線用 `context["locale"]`。

**沒授書就退回繁中**（不開天窗），但上架守門仍擋著不准開那個語系。

## 授書＝重寫，不是翻譯

一本書要在地化的東西：

| 項目 | 台灣 | 日本 |
|---|---|---|
| 急難號碼 | 119／1925 安心專線／1995 生命線／113 保護專線 | 119（消防救急）／110（警察）／#7119（要不要叫救護車）／0120-279-338 よりそいホットライン／地域包括支援センター（高齡受暴） |
| 傳統醫學 | 中醫（健保給付、⑥-TCM） | 漢方（醫師處方、健保給付、⑥-KAMPO） |
| 看診工具 | 回診小抄 | お薬手帳（每次就診與領藥都要帶） |
| 拒絕就醫的說法 | 「不用啦」「我休息一下就好」 | **「人に迷惑をかけたくない」（不想給人添麻煩）** ——要正面接住，不是說「不會麻煩」，而是「之後嚴重了反而更麻煩周圍的人」 |
| 關係壓力 | 情緒勒索、催婚催生 | **世間体**（別人怎麼看）＋不想添麻煩 |
| 語言分寸 | 台灣國語、繁體字、不夾英文 | ていねい語（です・ます）為底、**不用二重敬語**（過度尊敬反而生分）、自然的外來語可用、不混中文漢字 |
| 藥品法規 | 褪黑激素在台灣是處方藥 | 褪黑激素在日本未核准為一般販售的藥品 |

## 守門

- `scripts/test_persona_books.py`（掛在 `npm run test:launch`）：逐本檢查佔位符已填、章節骨架完整（⓪～⑦-B）、當地急難號碼在紅線裡、沒有殘留別國內容。
- `engine/test_voice_style_rules.py`：語音風格六節逐本檢查，含「不准連續兩輪反問」這條硬規矩。
- `engine/test_medical_escalation_asymmetry.py`：兩條線都必須傳語系（漏傳＝那條線永遠只吃中文版）。
