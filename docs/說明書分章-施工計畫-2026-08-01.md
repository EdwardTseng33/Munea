# 說明書分章 · 施工計畫（2026-08-01）

> Edward 2026-08-01 問：「這個不能有結構性的設計嗎？以前有說可以把資訊分層不同的附屬文件進行資料整理，這樣他在查詢或調用的時候才需要調用大量資料之類。」
> 這份是回答＋可以直接施工的清單。**尚未動工，等 Edward 拍板。**

---

## 一、現況（實際量過，不是估的）

| 項目 | 數字 |
|---|---|
| 她每輪講話前都要重讀的說明書 | **17,581 字**（中文） |
| 7/29 瘦身後 | 13,361 字 |
| 7/30 | 15,035 字 |
| 7/31 那版 | 17,581 字（三天胖 31%） |
| 其中最大一塊 | **10,400 字（六成）＝ 61 條規則擠在同一段**，不管聊什麼都全帶 |
| 英文地區資訊區塊 | 1,409 字（出現在中文通話裡） |

**已經有的分層（做對的部分）**：衛教庫 29 題 × 4 國**不在**說明書裡——她聽到「膝蓋痛」才把那一張補進去。所以題庫再大都不會拖慢她。要處理的是那 61 條規則。

---

## 二、能不能靠快取解決？不能

查證過（2026-08-01）：**Gemini 的語音線沒有「說明書先存起來、下次不用重讀」這種功能**——官方連線設定文件裡根本沒有這個欄位（只有連線續命與上下文壓縮，都不是快取）。

> 參考：https://ai.google.dev/gemini-api/docs/live-session ／ https://ai.google.dev/gemini-api/docs/caching
> 另有報導稱 OpenAI 的語音線 2026-07 加了這個、延遲砍 25%——**我在官方文件那頁沒親眼查到，列為情報、不當事實**。若屬實，是未來挑語音引擎的一個籌碼。

所以唯一有效的做法就是 Edward 講的那個：**平常只帶精簡版，聊到哪一塊才把那一塊補進去。**

業界 2026 已經把這件事做成標準做法，叫 *progressive disclosure*（一層一層才給）；最具體的形式是 Anthropic 2025-12 開放的 Agent Skills 標準（目錄層 → 整章 → 附件），OpenAI／Google／GitHub／Cursor 都跟進了。我們的衛教庫本來就是同一個模式。

## 三、三層設計

| 層 | 內容 | 何時進她腦袋 | 目標大小 |
|---|---|---|---|
| **L1 常駐** | 身分／語言／安全紅線／不准編造／講幾句話／稱呼 | 每輪都在 | ~12,000 字 |
| **L2 情境觸發** | 中醫、陪看醫生、情緒安撫三步、講故事結構、家人傳話紅線 | **他講到才補那一章**（跟衛教庫同一套機制） | 平常 0 |
| **L3 查了才拿** | 衛教題庫、即時查詢、記憶、側寫 | 已經是這樣 | 平常 0 |

**判準**（分不清時就照這條）：
> 這條規則是「任何一句話都可能犯」→ L1；「只有聊到某件事才會犯」→ L2。

## 四、可以搬的（逐條，含觸發詞）

| 規則 | 字數 | 觸發詞（聽到才補） |
|---|---|---|
| ⑦-B 轉述紅線（傳話只能複述、不准補細節） | 1,086 | 有家人傳話這通才帶 |
| 情緒安撫三步（接住／找原因／量身建議） | 624 | 難過、煩、睡不著、吵架、委屈… |
| ⑥-VISIT 陪他看醫生（幫他記／問／想起來） | 321 | 看醫生、回診、掛號、報告 |
| ④-B 情緒壓力／關係壓力（情緒勒索、催婚…） | 293 | 兒子／女兒／媳婦＋壓力類詞 |
| ⑥-TCM 中醫這條路 | 234 | 燥、火氣、氣虛、寒、補 |
| 講故事的結構（開頭轉折寓意） | 232 | 講個故事、說個笑話 |
| 英文地區資訊區塊瘦身 | 1,409 → ~400 | 中文通話只留必要欄位 |
| **合計可減** | **約 3,800～4,500 字（−22%～−26%）** | |

## 五、**不能**搬的（每一句都可能犯）

不准診斷／不准改藥／不准擋就醫（只往上推）／不准編造（來源自檢）／不准亂講急難號碼／講幾句話、句尾帶問／用哪個語言／稱呼怎麼叫／開場只打招呼。

---

## 六、施工順序（每一刀都可獨立退回）

1. **第 1 刀**：英文地區資訊瘦身（最安全、零行為改變）→ 減約 1,000 字
2. **第 2 刀**：⑦-B 轉述紅線改成「這通有傳話才帶」→ 減 1,086 字
3. **第 3 刀**：中醫＋陪看醫生＋情緒三步＋講故事，接上衛教庫同一套關鍵字機制 → 減約 1,500 字
4. 每刀之後跑一次 19 題聊天品質考卷＋各國安全考卷，**分數不准掉**才進下一刀

## 七、風險與怎麼防

| 風險 | 防法 |
|---|---|
| 規則搬出去後，觸發詞沒命中＝那輪沒有規則 | 只搬「只有聊到才會犯」的；安全紅線一律留 L1 |
| 關鍵字插一字就失效（7/29 踩過） | 沿用衛教庫既有的比對層，不自己再造一套 |
| 改完看起來沒事、其實某類問題退步 | 每刀跑考卷，分數掉就退回該刀 |

## 八、預期效果（誠實版）

- **確定**：每輪要重讀的字少約四分之一。
- **不確定**：能換到多少「她開口變快」——先做第 1、2 刀，用修好的儀表量出前後差距，再決定要不要做第 3 刀。**不先量就不承諾秒數。**
