# Android 實機測試指南（補助案 B1 查核點 · 2026-10-28）

給要在安卓手機上測沐寧的人看的。整個流程 10 分鐘，不用懂技術。

## 兩顆測試包，用途不同

| 測試包 | 哪裡來 | 登入方式 | 連哪台機器 | 用來做什麼 |
|---|---|---|---|---|
| **正式設定版**（`munea-android-debug-N`） | GitHub Actions「建置 Android debug APK」 | 真帳號（Google／Apple 登入） | 正式機 | 人拿手機裝、真帳號登入、真的通話 → **B1 實機欄** |
| **自動登入版**（`munea-android-devprofile-N`） | 同一次建置「登入與聊聊通話流程自動化」 | 機器自動登入（沒密碼、沒真帳號） | 測試機 | 給雲端「真機實驗室」自動跑流程、留截圖影片 |

兩顆都是 debug 簽章、不能上架，只做測試。

## 路 A：人拿安卓手機測（真帳號、真通話）

1. 蘇菲把「正式設定版」的 `app-debug.apk` 放到 Google 雲端硬碟 `Munea驗收項目/01-查核點證據/B1…/安裝檔/`，給你連結。
2. 手機開那個連結 → 下載 → 點開 → 系統會問「允許安裝未知來源的應用程式？」→ 允許（只對這次下載的 App）。
3. 開啟「Munea 沐寧」→ 看完三頁開場 → 點「用 Google 登入」→ 瀏覽器完成登入後**應該自動跳回 App**（2026-10-28 補了 Android 的回跳登記，之前會卡在瀏覽器回不來）。
4. 首頁 → 下方「聊聊」→ 「開始通話」→ 第一次會跳「開始聊之前，先跟你說一聲」→ 「我知道了，開始聊」→ 系統問麥克風權限 → 允許 → 跟寧寧講幾句。
5. 把這幾張截圖存下來：登入後首頁、聊聊頁、通話中畫面。回報「手機型號＋Android 版本＋有沒有接通＋哪裡卡」。

結果填進 `01-查核點證據/B1…/03-Android測試版-登入與聊聊流程測試紀錄-20261028.md` 的「實機」欄。

## 路 B：雲端真機實驗室（沒有安卓手機也能做）

Google 的 Firebase Test Lab 有真的實體手機（Galaxy A15、S22 等）可以遠端跑：

```bash
gcloud firebase test android run --type robo --app app-debug.apk --device model=a15,version=34,locale=zh_TW,orientation=portrait --timeout 5m --record-video --project gen-lang-client-0229303523
```

- 用「自動登入版」跑 → 真手機上安裝、開啟、走到聊聊／通話畫面，會留影片、截圖、系統日誌。
- 用「正式設定版」跑 → 只能證明在真手機上裝得上、開得起來、登入頁出得來（實驗室沒有帳號可登入，也不應該拿測試帳號上正式機）。
- 每天有免費額度（實體機 15 次），一次 5 分鐘內免費。

結果放在 Google Cloud Storage 的測試結果桶，蘇菲會把截圖／影片抓進 B1 證據夾。

## 老實話：什麼算、什麼不算

- 路 B 能證明「真手機裝得上、開得起來、流程點得過去」，**不能證明真帳號登入跟真人通話**——那兩格只有路 A 填得了。
- 模擬器與實驗室手機都沒有人對著麥克風講話，通話「接通」畫面之後的對話品質要靠路 A。
